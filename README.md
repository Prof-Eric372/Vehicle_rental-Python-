# VehicleRental

## About
A vehicle rental system built with Python using OOP concepts.
Python version of the Java VehicleRental project.

## Features
- List all vehicles
- List available vehicles
- Rent a vehicle by plate
- Return a vehicle by plate
- Customer registration
- Rental management with automatic price calculation

## Technologies
- Python 3.13
- Object-Oriented Programming (OOP)

## OOP Concepts Applied
- Inheritance
- Encapsulation
- Polymorphism
- Method Overriding

## How to Run
```bash
python main.py
```

## Classes
- `Vehicle` → base class
- `Car`, `Motorcycle`, `Truck` → inherit from Vehicle
- `Customer` → customer registration
- `Rental` → rental management
